# DouMCP（抖M）

DouMCP 是一个让 AI 助手通过 MCP 协议操控抖音的 LSPosed 模块。模块注入抖音进程内启动一个本地 MCP 服务，账号、会话、消息、视频、评论、搜索等能力以 MCP 工具的形式开放，供本机 AI 客户端（如支持 MCP 的聊天助手、自动化脚本）直接调用。

## 功能

- **账号**：列出已登录账号、切换账号、按关键词搜索账号、获取任意用户资料（支持展开全部字段）。
- **会话与消息**：会话列表与未读统计、消息分页读取、发送文本（支持引用消息）、发送图片、发送表情、撤回消息、编辑消息、消息表态（添加/取消）、输入状态、标记已读。
- **视频**：视频详情（视频/图文，含统计与播放地址）、用户作品列表。
- **评论**：读取视频评论（一级评论与楼中楼，含图片/@用户/表情）；发布评论（顶评、回复、楼中楼，正文可带云表情、**表情包（动图）与本地图片**）。
- **表情包**：表情包推荐清单（返回可直接打开的动图地址）、**已添加的表情集**及其中的表情（每个表情带文字描述，可按语义挑选）。
- **搜索**：综合搜索（聚合结果，支持类型过滤）。
- **数据库**：列出并查询抖音本地数据库，支持加密库读取。
- **系统**：获取当前时间等基础工具。

## 工作原理与安全

- 模块在抖音进程内启动 Ktor 服务，监听本机端口 19320，使用 Streamable HTTP 传输。
- 服务使用 Bearer Token 鉴权，Token 在模块的"抖M设置"中配置；未持有 Token 的请求会被拒绝。
- 服务仅监听本地回环地址，仅供设备上的 AI 客户端连接。
- 消息发送、评论发布、图片上传等写操作均调用抖音自身链路完成，模块不做协议绕过。

## 适用范围

- Android 8.0（API 26）及以上，使用支持 LibXposed API 102 的框架（如 LSPosed）。
- 作用域：`com.ss.android.ugc.aweme`（抖音）。
- 宿主基线为抖音 40.6.0（versionCode 400601）；抖音版本更新可能导致部分功能失效，需等待模块适配。

## 安装与启用

1. 从本仓库的 Release 下载并安装 APK（按手机 CPU 架构选一个，现役机型基本都是 `arm64-v8a`）。
2. 在 LSPosed 中启用模块，勾选抖音作用域。
3. 打开抖音，在"我 → 设置"中进入"抖M设置"，配置端口与 Token。
4. 在 AI 客户端中以 Streamable HTTP 方式连接 `http://127.0.0.1:19320`，填入 Token 即可。

## 注意事项

- 需要登录的功能在未登录时会返回明确错误。
- 评论发布有平台频率限制，短时间连发可能被静默过滤（请求成功但不出现在评论区）。
- 抖音切到后台后会被系统冻结，此时 MCP 服务不响应；把抖音切回前台即可恢复。
- 发出的消息与评论遵循平台规则，发布内容是否展示以平台审核为准。
